# 📊 Netflix Movies & TV Shows – Power BI Dashboard

A beginner-friendly **Power BI mini project** created to practice data analysis and visualization using the Netflix Titles dataset.

## 📌 About the Project

This dashboard analyzes Netflix Movies and TV Shows based on:

* 🎬 Movies & TV Shows
* 🌍 Countries
* 📅 Release Year
* ⭐ Ratings
* 🎭 Genres

### 📊 Key Metrics

* **Total Titles:** 8.8K
* **Movies:** 6.13K
* **TV Shows:** 2.68K
* **Genres:** 515
* **Directors:** 4,527

## 🛠️ Tools Used

* Microsoft Power BI
* Netflix Titles Dataset
